빌드, 테스트, 수정을 순차적으로 실행하는 전체 QA 파이프라인입니다.

## 실행 순서

1. **빌드 단계**: `./gradlew build -x test`를 실행합니다.
   - 실패 시 컴파일 에러를 분석하고 수정한 뒤 재빌드합니다.

2. **테스트 단계**: `./gradlew test`를 실행합니다.
   - 모든 테스트 통과 시 3단계로 이동합니다.
   - 실패한 테스트가 있다면:
     a. 실패 원인을 분석합니다.
     b. 프로덕션 코드 버그이면 프로덕션 코드를 수정합니다.
     c. 테스트 기대값 오류이면 테스트를 수정합니다.
     d. 수정 후 테스트를 다시 실행합니다.
     e. 모든 테스트가 통과할 때까지 반복합니다.

3. **결과 보고**: 아래 형식으로 최종 결과를 출력합니다.
   - 빌드 결과 (성공/실패 후 수정)
   - 테스트 결과 (전체 수 / 성공 / 실패)
   - 수정 사항 목록 (있는 경우)
   - 최종 상태 (PASS / FAIL)
