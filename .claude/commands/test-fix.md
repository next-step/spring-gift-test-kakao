실패한 테스트를 자동으로 분석하고 수정해주세요.

## 실행 순서

1. `./gradlew test`를 실행하여 실패한 테스트를 식별합니다.
2. 실패한 테스트가 없으면 "모든 테스트 통과. 수정할 항목 없음"을 출력하고 종료합니다.
3. 실패한 테스트가 있다면:
   a. 테스트 코드와 프로덕션 코드를 함께 읽고 실패 원인을 분석합니다.
   b. 테스트의 기대값이 잘못된 것인지, 프로덕션 코드의 버그인지 판단합니다.
   c. 프로덕션 코드의 버그라면 프로덕션 코드를 수정합니다.
   d. 테스트의 기대값이 잘못된 것이라면 테스트를 수정합니다.
4. 수정 후 `./gradlew test`를 다시 실행하여 통과를 확인합니다.
5. 수정 내용을 요약합니다.
